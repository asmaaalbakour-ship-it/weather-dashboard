# 🌤️ Weather Dashboard

A responsive weather dashboard built with **Vue.js** that allows users to check current weather information and forecasts for different cities.

## ✨ Features

* 🌡️ Display current weather information
* 📅 View weather forecasts
* 🌍 Search for different cities
* ⭐ Save favorite cities
* 📱 Responsive design
* ⚡ Fetch weather data using an API
* 🚨 Handle network and API errors

## 🛠️ Technologies

* Vue.js
* JavaScript
* HTML5
* CSS3
* Axios / Fetch API
* Weather API

## 🚀 Getting Started

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Then open the local URL shown in your terminal.

This project was created to practice building a Vue.js application, working with APIs, handling asynchronous data, and creating a responsive user interface.
